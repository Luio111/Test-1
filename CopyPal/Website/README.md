# CopyPal Website

Statische Landingpage (ROADMAP M10) ohne externe Skripte oder Schriften: `index.html`, `impressum.html`, `datenschutz.html`, `style.css`.

Veröffentlichen (z. B. GitHub Pages im öffentlichen Release-Repository, D1):

1. Ordnerinhalt in den Pages-Branch kopieren, dazu `appcast.xml` aus `scripts/release.sh`.
2. `OWNER/REPO` im Download-Link ersetzen.
3. Impressum und Datenschutzerklärung ausfüllen. Die markierten Stellen sind Vorlagen und keine Rechtsberatung.
