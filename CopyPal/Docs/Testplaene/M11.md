# Testplan M11 – Bildschirmfoto

## Automatisch geprüft (CI)

- Das Tastenkürzel ⌘⇧A ist registriert. ⌘⇧A öffnet das Overlay oder das Berechtigungsfenster, Esc schließt beides. Das Berechtigungsfenster fragt die Freigabe nie von selbst an.
- Direkt danach fügt kurzes ⌘V genau einmal ein (Geste unverändert).
- Zusammensetzen auf synthetischen Bildern: drei Abschnitte, erwartete Höhe.
- Nur mit Bildschirmaufnahme-Freigabe auf dem Runner: Ein Bereich landet als Bild im Verlauf und als PNG + TIFF in der Zwischenablage. Sonst „übersprungen“ mit `::warning::` im Protokoll.
- Linux: Auswahl-Automat, Kandidatenkette, Kontrastbereiche, Zeilen-Signaturen, Zusammensetzen, Scroll-Planung, Diagnosebericht.
- Protokolle enthalten nie Bildinhalte, nur Größe, Dauer und Ergebnis.

## Vorbereitung

- Frischer Zustand: `scripts/reset-dev-state.sh`, zusätzlich `tccutil reset ScreenCapture <bundle-id>`.
- Labor (Debug-Build) → „Bildschirmfoto (M11)“: „Erkannte Bereiche im Overlay zeigen“ hilft beim Einrasten-Test, „Letzter Schritt“ beim Erweitern.
