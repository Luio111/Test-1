# Testplan M7 – Notch, Onboarding, Einstellungen, Start bei Anmeldung

## Automatisch geprüft (CI)

- Notch-Geometrie: Rechteck der Notch, Pop-up darunter, Kapsel „Kopiert“ an der Notch.
- Bildschirmwahl: der Bildschirm mit dem aktiven Fenster, sonst der mit dem Mauszeiger.
- Alle Einstellungen werden ohne Neustart übernommen (Ignorierliste und Pause im Selbsttest).
