# Testplan M1 – ⌘V halten, Einfügen, Fokus

Ziel: zeigen, dass die Kerninteraktion zuverlässig und schnell genug ist, und die Werte für Halteschwelle und Wartezeit festlegen. Das Pop-up zeigt noch **8 Platzhalter**, der echte Verlauf kommt in M4.

**Achtung:** Beim Einfügen aus dem Pop-up legt CopyPal den Platzhalter in deine Zwischenablage. Wichtiges vorher woanders sichern.

## Vorbereitung

- [ ] Im Ordner `Test-1`: `git switch claude/amazing-volta-1uce5i && git pull`, dann `cd CopyPal && ./scripts/bootstrap.sh`
- [ ] In Xcode ⌘R; Diagnose zeigt Bedienungshilfen „Erteilt“
- [ ] Menüleiste → **Labor …** öffnen und daneben liegen lassen (Status „Event-Tap: Läuft“)
- [ ] TextEdit öffnen, neues Dokument im Rich-Text-Modus (Format → In formatierten Text umwandeln)
