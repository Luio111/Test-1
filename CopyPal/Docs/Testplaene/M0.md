# Testplan M0 – Fundament

Ziel: Das App-Gerüst baut bei dir und in der CI, ist stabil signiert, und die Diagnose liefert die Ausgangswerte für M1/M2.

## Vorbereitung (einmalig)

- [x] `brew install xcodegen gh`
- [x] Repository klonen (einmalig): `gh auth login`, dann `cd ~/Developer && gh repo clone Luio111/Test-1 && cd Test-1` (siehe README)
- [x] Xcode → Settings… → Accounts: Apple ID angemeldet, unter Manage Certificates… ein „Apple Development“-Zertifikat vorhanden (siehe README)
- [x] PR-Branch holen: `git fetch origin && git switch claude/amazing-volta-1uce5i`
- [x] `cd CopyPal && ./scripts/bootstrap.sh --open` → meldet deine Team-ID
