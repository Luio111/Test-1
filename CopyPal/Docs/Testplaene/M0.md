# Testplan M0 – Fundament

Ziel: Das App-Gerüst baut bei dir und in der CI, ist stabil signiert, und die Diagnose liefert die Ausgangswerte für M1/M2.

## Vorbereitung (einmalig)

- [ ] `brew install xcodegen gh`
- [ ] Repository klonen (einmalig): `gh auth login`, dann `cd ~/Developer && gh repo clone Luio111/Test-1 && cd Test-1` (siehe README)
- [ ] Xcode → Settings… → Accounts: Apple ID angemeldet, unter Manage Certificates… ein „Apple Development“-Zertifikat vorhanden (siehe README)
- [ ] PR-Branch holen: `git fetch origin && git switch claude/amazing-volta-1uce5i`
- [ ] `cd CopyPal && ./scripts/bootstrap.sh --open` → meldet deine Team-ID

## Checkliste

| # | Schritt | Erwartet | ✓ |
|---|---|---|---|
| 1 | CI-Lauf im Pull Request ansehen | beide Jobs grün | |
| 2 | In Xcode ⌘R | Clipboard-Symbol in der Menüleiste, **kein** Dock-Icon, kein Fenster (Symbol fehlt? → Troubleshooting „Kein Symbol in der Menüleiste“) | |
| 3 | Menüleiste → Diagnose … | Fenster erscheint im Vordergrund, hell/dunkel passend zum System | |
| 4 | Diagnose → Signatur | Tag „Stabil“ + deine Team-ID | |
| 5 | Terminal: `codesign -dv --verbose=4 ~/Library/Developer/Xcode/DerivedData/CopyPal-*/Build/Products/Debug/CopyPal.app 2>&1 \| grep -E 'Authority\|TeamIdentifier'` | `Authority=Apple Development: …`, deine Team-ID | |
| 6 | Diagnose → Bedienungshilfen → „Anfragen“, in den Systemeinstellungen freigeben | Tag springt ohne Neustart auf „Erteilt“ | |
| 7 | Beliebige Codeänderung (z. B. Leerzeile), erneut ⌘R, Diagnose öffnen | Bedienungshilfen weiterhin „Erteilt“ | |
| 8 | Diagnose → Zwischenablage → „Zugriff für CopyPal“ | Wert notieren | |
| 9 | Etwas kopieren, dann „Lesetest → Jetzt testen“ | Formate werden angezeigt; **notieren, ob macOS einen Hinweis/Dialog zeigt** | |
| 10 | Team-ID im Fenster markieren, ⌘C, irgendwo einsetzen | Team-ID wurde kopiert | |
| 11 | „Bericht kopieren“ | Button zeigt kurz „Kopiert ✓“; der eingefügte Bericht enthält **nicht** deinen Namen/deine E-Mail | |
| 12 | ⌘W im Diagnose-Fenster | Fenster schließt | |
| 13 | CopyPal.app erneut öffnen (Finder oder `open`) | Diagnose-Fenster erscheint | |
| 14 | Terminal: `swift test --package-path Packages/CopyPalKit` | alle Tests grün | |
| 15 | Diagnose im Vordergrund → ⌘Q | App beendet sich | |
