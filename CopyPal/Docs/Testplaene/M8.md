# Testplan M8 – Härtung, Performance, Kompatibilität

## Automatisch geprüft (CI)

- 100 schnelle Kopien (`pbcopy`-Schleife nachgestellt): kein Absturz, keine Duplikate, der letzte Eintrag stimmt.
- Ein Bild mit etwa 20 MB blockiert den Main-Thread nicht (Grenze 250 ms auf der CI-VM).
- Messwerte im CI-Protokoll: Pop-up-Latenz, CPU im Leerlauf, Speicher.
- Protokolle enthalten nie Inhalte, nur Art, Anzahl, Größe und Grund.
